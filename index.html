Ship Cable Orders & Delivery Tracking System

Stack
Supabase · Postgres · React · Vercel
Role
Sole designer and developer
Status
In production, phased build ongoing

An internal system for a supplier of cables to ships, replacing scattered Excel files with one source of truth. The data model runs Project → Vessel → Cable, tracking every cable by length in metres across contract, ordered and delivered figures, with a separate cutting-request workflow that rolls up into cut and remaining totals.

  • Retired the spreadsheet handover: roll-up totals compute per vessel and per project instead of being re-keyed.
  • Excel export with a column picker, so the office keeps the reporting format it already uses.
  • Search, filter and sort across cable tables that had previously been scanned by eye.
